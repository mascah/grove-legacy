## Meaning

The harness process that carries out an [attempt](G-260921-sth8q-attempt.md):
the executable Grove starts in the attempt's worktree, the event stream it
reads back, and that harness's own vocabulary for model, effort, permission
and cap. Claude Code is the provider today; Codex is selected as the second
by [G-260928-vdhf0](G-260928-vdhf0-run-attempts-on-codex-as.md) and built by
[G-260928-y2p5h](G-260928-y2p5h-run-an-attempt-on-codex.md). A provider is
chosen per launch and recorded in the attempt's facts, so two attempts of one
work may run on different providers. The board and `attempt` already say "the
attempt's provider" in this sense.

## Relationships

An attempt has exactly one provider. Grove's owner process, worktree, cap,
stop and result reconciliation are Grove's whatever the provider. The
[review](G-260921-rz7bn-review.md) an attempt dispatches runs as the provider's
own subagent where it has one, or as a separately launched process
([G-260928-n4f1q](G-260928-n4f1q-review-a-candidate-as-a.md)).

## Not

Not the model: a provider runs several. Not the owner process, which is
Grove's. Not an entrypoint ([G-260925-m9jcr](G-260925-m9jcr-entrypoint-revision.md)):
those are the files `init` writes for a harness to load the guides, and exist
per harness whether or not Grove runs attempts on it.
